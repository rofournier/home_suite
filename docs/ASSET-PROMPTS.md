# 🖼️ Prompts ChatGPT Image — V1 (4 générations)

**Comment s'en servir**
- Colle le bloc **STYLE ANCHOR** au début de CHAQUE prompt (cohérence inter-assets).
- Demande le **fond transparent (PNG alpha)**. Si l'outil ne le tient pas, il génère sur un aplat uni (mint `#B7E4C7`) facile à détourer ensuite.
- Formats : **maisons = 1024×1536 (portrait 2:3)** · **planches = 1024×1024**.

---

## 🔖 STYLE ANCHOR (à coller partout)
> Cozy 2D anime illustration, **"Lofi Girl / ChilledCow" aesthetic** — Studio Ghibli-inspired hand-painted look, warm **desaturated** palette, soft ambient lighting, gentle film grain & paper texture, soft shadows, nostalgic "lofi beats to relax/study to" mood. Clean readable shapes, one consistent soft light source from the upper-left. Flat front-facing orthographic view. **No text, no watermark, no UI.**
